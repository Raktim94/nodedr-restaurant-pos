# Engineering and security audit, November 2026

Scope: `master` at v1.31.0 (backend NestJS/Prisma, web Next.js, Capacitor mobile offline layer).
Method: read-only review, then fixes with regression tests. Every status below says what was actually run.
Not done in this pass: NFC (NTAG 424 DNA) ordering, the new table state machine, the mobile redesign and any
deployment. They are separate releases and are listed under "Open".

Skills: the Cloudflare `security-audit` skill (github.com/cloudflare/security-audit-skill, commit c1c8a8c, MIT) and Google's
`modern-web-guidance` (npm 1.0.0, Apache-2.0) were installed later in this pass, after reading their scripts. The skill run
is written up in `docs/SECURITY-AUDIT-SKILL-RUN-1.md` (quick profile, partial coverage). The first part of this document
(A-01 to A-12) predates the skills and used OWASP guidance and framework documentation.

## Skill run findings (Cloudflare security-audit, November 2026)

Six confirmed findings fixed with regression tests (`security-audit.e2e-spec.ts`: 8 of 9 failed on the old code):
a high-severity one (server-wide backup, update and sync open to any restaurant's owner on a shared server), a medium
one (no privilege ceiling when assigning roles or managing accounts), and four low ones (webhook SSRF guard missing
IPv6-embedded IPv4, guest payment routes without the table grant, email login collision, non-positive refunds via MCP).
One finding is left needing validation (per-session join lockout). Buzzer webhooks now refuse link-local and
cloud-metadata addresses and do not follow redirects. Six areas the critic found uncovered are deferred
(integration API keys, realtime gateway, public uploads/redirects, offline-sale intake and printer access, remaining
outbound calls, buzzer webhook LAN targets). Candidate validation was done by the parent, not by independent verifiers.
